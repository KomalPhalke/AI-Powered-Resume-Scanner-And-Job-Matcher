# AI-Powered Resume Scanner & Job Matcher

## Overview
An NLP-based web application developed using Python and Streamlit to compare resumes with job descriptions and calculate resume-job similarity scores.

## Features
- Upload resumes and job descriptions
- Calculate resume-job similarity scores using TF-IDF and Cosine Similarity
- Identify matching keywords between resumes and job descriptions
- Interactive Streamlit web interface
- Text preprocessing and exploratory data analysis (EDA)

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- NLP
- TF-IDF Vectorization
- Cosine Similarity

## How to Run
1. Clone this repository.
2. Install the required libraries:

pip install -r requirements.txt

3. Run the application:

streamlit run app.py
